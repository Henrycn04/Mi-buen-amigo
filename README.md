# Mi-buen-amigo

Este proyecto implementa un chatbot en Python llamado CompaGPT, utilizando la API de Gemini. El objetivo es simular una conversación natural con un “compa” de estilo costarricense, mediante el uso de prompt engineering para definir una personalidad cercana, amigable y relajada. El sistema permite mantener una conversación continua con el usuario desde la terminal, y gestiona la API key de forma segura mediante un archivo local excluido del repositorio. Este proyecto demuestra el uso básico de modelos de lenguaje, manejo de contexto conversacional y personalización de respuestas.

## Para correr
1. Crear el archivo `apikey.txt` con una API key de Gemini.
2. Correr el main.py:

```bash
python main.py
